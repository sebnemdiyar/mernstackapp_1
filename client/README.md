## MernStackApp

MernStackApp, kullanıcıların kayıt ve giriş işlemlerini gerçekleştirebildiği, kimlik doğrulama ve yetkilendirme süreçlerinin yönetildiği modern bir web uygulamasıdır. CRUD işlemleri sayesinde verilerin oluşturulması, görüntülenmesi, güncellenmesi ve silinmesini sağlayan kullanıcı dostu bir arayüze sahiptir.

## Özellikler

- Kullanıcı kayıt (Register) ve giriş (Login) işlemleri
- Authentication (Kimlik Doğrulama)
- Authorization (Yetkilendirme)
- Kullanıcı bazlı erişim kontrolü
- CRUD işlemleri (Create, Read, Update, Delete)
- Form ve veri yönetimi
- Global state yönetimi
- API üzerinden veri alışverişi
- Bildirim mesajları
- Responsive tasarım

## Kullanılan Teknolojiler

- React
- Next.js
- React Router DOM
- React Icons
- Redux Toolkit
- React Redux
- Axios
- Tailwind CSS
- React Toastify
